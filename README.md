## 💡 What is Thozhi?

**Thozhi** (meaning *"Friend"* in Tamil) is not just a mobile application — it is a **connected safety ecosystem** built specifically for women. In a world where harassment, unsafe travel, and delayed emergency response remain critical threats, Thozhi stands as an always-on, AI-powered guardian.

From a **one-tap SOS** that instantly alerts family and police, to **PPG-based panic detection** through your phone's camera, to **AI-optimized safe route navigation** — Thozhi provides a full circle of protection that travels with every woman, every day.

## 🌟 Solution Overview

> Thozhi transforms reactive panic into **proactive, intelligent protection** through a multi-layered safety ecosystem.

<br/>

### 🔴 One-Tap SOS
Instant emergency trigger that simultaneously alerts family members, nearby police units, and emergency contacts — with live location, audio capture, and incident logging — all in under 3 seconds.

### 📍 Live GPS Tracking
Continuous real-time location sharing with the family safety squad. Track exact position, speed, and movement patterns. Shareable via secure link.

### 🗺️ AI Safe Route Navigation
Powered by Google Maps + risk analysis engine. Routes are scored based on lighting, reported incident density, crowd presence, and time-of-day risk factors.

### 👮‍♀️ Nearest Police Matching
Automatically identifies and navigates the nearest available women police officer to the incident location — with direct in-app communication channel.

### 👨‍👩‍👧 Family Safety Squad
Create a trusted network of family and friends. All squad members receive instant SOS alerts, live tracking links, and can initiate check-in pings.

### 🎙️ Audio Evidence Recording
Automatic background audio capture on SOS activation. Evidence is securely encrypted, timestamped, and stored — tamper-proof and admissible.

### 🧠 AI Risk Detection
Real-time risk scoring based on route history, location patterns, crowd data, and incident reports. Proactively warns before entering danger zones.

### 📐 Geofencing Alerts
Define safe zones (home, college, office). Automatic alerts trigger when the user exits a geofence unexpectedly or enters flagged high-risk zones.

### 📵 Offline SOS Fallback
When internet is unavailable, Thozhi falls back to SMS-based SOS — automatically sending pre-configured emergency messages with last-known GPS coordinates.

### 💓 PPG Panic Detection
Using the phone camera and flash, Thozhi measures heart rate via photoplethysmography. Elevated BPM triggers automatic emergency escalation without user action.

### 📊 Real-Time Incident Monitoring
Live dashboard for police and family — track active SOS events, response status, officer assignment, and case resolution in real time.

### 🌍 Multilingual Communication
Tamil and English support for in-app secure chat between users and assigned police officers. Barrier-free emergency communication.

## 💓 PPG Panic Detection Workflow

> *Photoplethysmography (PPG)* — detecting panic through your heartbeat, using just your phone's camera.

```
Step 1  ──▶  User opens Panic Check screen
               │
Step 2  ──▶  User places finger on rear camera + flash activates
               │
Step 3  ──▶  Camera captures light absorption variations (PPG signal)
               │
Step 4  ──▶  Signal processed → Heart Rate (BPM) calculated in real time
               │
Step 5  ──▶  BPM analyzed against stress thresholds
               │
            ┌──────────────────────────────┐
            │  Normal (60–100 BPM)         │──▶  "You are calm. Stay safe." ✅
            │  Elevated (100–130 BPM)      │──▶  "Are you okay?" prompt shown ⚠️
            │  Critical (>130 BPM / spike) │──▶  Emergency auto-triggered 🚨
            └──────────────────────────────┘
               │
Step 6  ──▶  SOS auto-dispatched (no user action required)
               │
Step 7  ──▶  Alerts sent to Family Squad + Nearest Police Officer
```

**Key technical details:**

| Aspect | Implementation |
|---|---|
| 📷 **Signal Source** | Rear camera + LED flash (rPPG technique) |
| 📈 **BPM Analysis** | Peak detection on green channel signal |
| 🧠 **Stress Detection** | Threshold-based + rate-of-change analysis |
| 🔐 **Privacy** | No biometric data stored; only emergency trigger stored |
| ⚡ **Response Time** | < 5 seconds from detection to SOS dispatch |
| 📵 **Offline Mode** | Falls back to SMS SOS if internet unavailable |

## 🔐 Security & Privacy

> Thozhi is built with a **privacy-first, security-by-design** approach.

| 🔒 Layer | Implementation |
|---|---|
| **End-to-End Encryption** | All chat messages & location data encrypted in transit and at rest |
| **Secure Evidence Storage** | Audio recordings stored in encrypted Firebase Cloud Storage with access control |
| **JWT Authentication** | All API calls require valid signed tokens — no anonymous access |
| **OAuth 2.0** | Google Sign-In follows OAuth 2.0 flow — no passwords stored |
| **Tamper-Proof Logs** | Incident logs are immutable — timestamped and hash-verified |
| **Role-Based Access Control** | Women, Family, Police, Admin — each role sees only their permitted data |
| **Data Privacy** | No biometric data stored permanently; PPG data discarded post-analysis |
| **Auto Data Deletion** | User data auto-deleted after configurable retention period |
| **Incognito Mode** | Option to hide live location from all parties except emergency services |
| **Audit Logs** | All admin and police actions are logged and monitored |

## ⚙️ Installation & Setup

### Prerequisites

- Node.js v18+
- npm or yarn
- Expo CLI (`npm install -g expo-cli`)
- Android Studio / Xcode (for device emulation)
- Firebase project configured
- Google Cloud project with Maps API enabled

### 1. Clone the Repository

```bash
git clone https://github.com/akash14102006/Thozhi-App.git
cd Thozhi-App/girl-mobile-app
```

### 2. Install Frontend Dependencies

```bash
npm install
```

### 3. Install Backend Dependencies

```bash
cd backend
npm install
cd ..
```

### 4. Configure Environment Variables

```bash
# Copy the example env file
cp .env.example .env

# Fill in your credentials
nano .env
```

**Frontend `.env` variables:**

```env
EXPO_PUBLIC_FIREBASE_API_KEY=your_firebase_api_key
EXPO_PUBLIC_FIREBASE_AUTH_DOMAIN=your_project.firebaseapp.com
EXPO_PUBLIC_FIREBASE_PROJECT_ID=your_project_id
EXPO_PUBLIC_FIREBASE_STORAGE_BUCKET=your_project.appspot.com
EXPO_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=your_sender_id
EXPO_PUBLIC_FIREBASE_APP_ID=your_app_id
EXPO_PUBLIC_GOOGLE_MAPS_API_KEY=your_google_maps_key
EXPO_PUBLIC_API_BASE_URL=http://localhost:3001
```

**Backend `backend/.env` variables:**

```env
PORT=3001
MONGO_URI=your_mongodb_connection_string
EMAIL_USER=your_email@gmail.com
EMAIL_PASS=your_email_app_password
OTP_SECRET=your_otp_signing_secret
```

### 5. Run the Backend Server

```bash
cd backend
node server.js
```

### 6. Run the Mobile App

**Android:**
```bash
npx expo start --android
```

**iOS:**
```bash
npx expo start --ios
```

**Expo Go (Physical Device):**
```bash
npx expo start
# Scan QR code with Expo Go app
```
