## Overview

**Thozhi** — meaning *Friend* in Tamil — is a production-grade women safety platform built for real-world emergency response. It goes beyond panic buttons: Thozhi creates a living, intelligent safety network that connects every woman to her family, to verified police officers, and to an AI risk engine — all in real time.

The platform is engineered for three simultaneous goals: **instant response**, **intelligent prevention**, and **evidence integrity**. Whether a user is a college student commuting late at night, a working woman in an unfamiliar city, or a family member monitoring a loved one's journey — Thozhi delivers a unified safety experience across every role.

> Thozhi is not just an application. It is a connected safety ecosystem designed to ensure every woman travels with confidence, support, and real-time protection.

## Solution Overview

*Protection beyond panic buttons.*

Thozhi transforms reactive panic into proactive, intelligent protection through a multi-layered safety ecosystem.

**One-Tap SOS**
Instant emergency trigger that simultaneously alerts family, nearby police units, and emergency contacts — with live location, audio capture, and incident logging — in under 3 seconds.

**Live GPS Tracking**
Continuous real-time location sharing with the family safety squad. Tracks exact position, speed, and movement patterns. Shareable via secure link.

**AI Safe Route Navigation**
Powered by Google Maps and a risk analysis engine. Routes are scored based on lighting conditions, reported incident density, crowd presence, and time-of-day risk factors.

**Nearest Police Matching**
Automatically identifies and navigates the nearest available women police officer to the incident location — with a direct in-app secure communication channel.

**Family Safety Squad**
A trusted network of family and friends. All members receive instant SOS alerts, live tracking links, and can initiate check-in pings.

**Audio Evidence Recording**
Automatic background audio capture on SOS activation. Evidence is encrypted, timestamped, and stored in tamper-proof cloud storage.

**AI Risk Detection**
Real-time risk scoring based on route history, location patterns, crowd data, and incident reports. Proactively warns before entering danger zones.

**Geofencing Alerts**
Define safe zones — home, college, office. Automatic alerts trigger on unexpected geofence exits or entry into flagged high-risk areas.

**Offline SOS Fallback**
When internet is unavailable, Thozhi falls back to SMS-based SOS — automatically sending pre-configured emergency messages with last-known GPS coordinates.

**PPG Panic Detection**
Using the phone camera and flash, Thozhi measures heart rate via photoplethysmography. Elevated BPM triggers automatic emergency escalation without user action.

**Real-Time Incident Monitoring**
Live dashboard for police and family — track active SOS events, response status, officer assignment, and case resolution in real time.

**Multilingual Communication**
Tamil and English support for in-app secure chat between users and assigned police officers.

## PPG Panic Detection

*AI that reads danger before you feel it.*

> **Photoplethysmography (PPG)** — detecting panic through your heartbeat, using only your phone's camera.

```
Step 1   User opens Panic Check screen
           |
Step 2   Finger placed on rear camera — flash activates
           |
Step 3   Camera captures light absorption variations (PPG signal)
           |
Step 4   Signal processed — Heart Rate (BPM) calculated in real time
           |
Step 5   BPM analyzed against clinical stress thresholds
           |
         Normal (60-100 BPM)    ->  "You are calm. Stay safe."
         Elevated (100-130 BPM) ->  Prompt shown: "Are you okay?"
         Critical (>130 BPM)    ->  Emergency auto-triggered
           |
Step 6   SOS dispatched automatically (no user action required)
           |
Step 7   Alerts sent to Family Squad and nearest Police Officer
```

| Aspect | Implementation |
|---|---|
| Signal Source | Rear camera and LED flash using rPPG technique |
| BPM Analysis | Peak detection on green channel signal |
| Stress Detection | Threshold-based with rate-of-change analysis |
| Privacy | No biometric data stored — only emergency trigger logged |
| Response Time | Under 5 seconds from detection to SOS dispatch |
| Offline Mode | Falls back to SMS SOS if internet is unavailable |

## Security and Privacy

*She moves. We protect. No one else sees.*

Thozhi is built with a privacy-first, security-by-design architecture. Every layer of the platform enforces strict access control, encryption, and audit integrity.

| Layer | Implementation |
|---|---|
| End-to-End Encryption | All messages and location data encrypted in transit and at rest |
| Secure Evidence Storage | Audio stored in encrypted Firebase Cloud Storage with role-based access |
| JWT Authentication | All API calls require valid signed tokens — no anonymous access |
| OAuth 2.0 | Google Sign-In follows the OAuth 2.0 flow — no passwords stored |
| Tamper-Proof Logs | Incident logs are immutable — timestamped and hash-verified |
| Role-Based Access Control | Woman, Family, Police, and Admin roles each access only permitted data |
| Data Privacy | No biometric data stored permanently — PPG data discarded post-analysis |
| Auto Data Deletion | User data auto-deleted after configurable retention period |
| Incognito Mode | Option to hide live location from all parties except emergency services |
| Audit Logs | All admin and police actions are logged and monitored |

## Installation

*Up and running in minutes. Protecting lives immediately.*

### Prerequisites

- Node.js v18 or higher
- npm or yarn
- Expo CLI — `npm install -g expo-cli`
- Android Studio or Xcode for device emulation
- Firebase project configured
- Google Cloud project with Maps API enabled

### Clone the Repository

```bash
git clone https://github.com/akash14102006/Thozhi-App.git
cd Thozhi-App/girl-mobile-app
```

### Install Frontend Dependencies

```bash
npm install
```

### Install Backend Dependencies

```bash
cd backend
npm install
cd ..
```

### Configure Environment Variables

```bash
cp .env.example .env
```

**Frontend `.env`**

```env
EXPO_PUBLIC_FIREBASE_API_KEY=your_firebase_api_key
EXPO_PUBLIC_FIREBASE_AUTH_DOMAIN=your_project.firebaseapp.com
EXPO_PUBLIC_FIREBASE_PROJECT_ID=your_project_id
EXPO_PUBLIC_FIREBASE_STORAGE_BUCKET=your_project.appspot.com
EXPO_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=your_sender_id
EXPO_PUBLIC_FIREBASE_APP_ID=your_app_id
EXPO_PUBLIC_GOOGLE_MAPS_API_KEY=your_google_maps_key
EXPO_PUBLIC_API_BASE_URL=http://localhost:3001
```

**Backend `backend/.env`**

```env
PORT=3001
MONGO_URI=your_mongodb_connection_string
EMAIL_USER=your_email@gmail.com
EMAIL_PASS=your_email_app_password
OTP_SECRET=your_otp_signing_secret
```

### Start the Backend Server

```bash
cd backend
node server.js
```

### Run on Android

```bash
npx expo start --android
```

### Run on iOS

```bash
npx expo start --ios
```

### Run with Expo Go

```bash
npx expo start
# Scan the QR code with the Expo Go app
```
